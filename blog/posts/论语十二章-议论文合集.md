# 物质穿膜层数的计算方法

# 物质穿膜层数的计算方法

---

## 一、计算的核心原理

### 1. 最基本的一条规则

> **物质从细胞一侧进入、从另一侧穿出（即"穿过一个细胞"）= 穿过 2 层生物膜**

```
        细胞外液
   ────────╱╲────
     ①    ╱  ╲   ②
        细胞膜      细胞膜
        ╲  ╱
   ──────╲╱──────
        细胞外液
   
   从左侧到右侧穿过该细胞 = 2 层膜
```

### 2. 几种常见结构的穿膜层数

| 结构 | 穿膜层数 | 说明 |
| --- | --- | --- |
| 穿过**一个细胞** | **2层** | 进一出一 |
| 穿过**单层细胞壁**（如毛细血管壁） | **2层** | 该壁由单层细胞构成，进入+出去=2 |
| 穿过**小肠绒毛上皮细胞** | **2层** | 单层柱状上皮，进入+出去=2 |
| 穿过**肺泡壁+毛细血管壁** | **4层** | 2层细胞×每细胞2膜=4 |
| 穿过**肾小球毛细血管壁** | **不计层** | 病理/生理状态下为**滤过**，可认为是无膜穿过的滤过作用 |



---

## 二、解题"三步法"

### 第①步：明确起点和终点

> 物质从哪里 → 到哪里？

### 第②步：画出路径，标注**经过了哪些细胞/结构**

> 尤其注意：**穿过一个细胞 = 2层膜**

### 第③步：逐段累加，不要遗漏

---

## 三、经典题型逐一分析

### 【题型1】O₂从肺泡 → 血液中的红细胞

**路径：**

```
肺泡(气) → 肺泡壁上皮细胞 → 间质 → 毛细血管壁细胞 → 血浆 → 红细胞
```

**逐段计算：**

| 阶段 | 穿过的结构 | 穿膜层数 |
| --- | --- | --- |
| 肺泡壁 | 穿过1个肺泡上皮细胞 | 2层 |
| 毛细血管壁 | 穿过1个毛细血管内皮细胞 | 2层 |
| 进入红细胞 | 穿过红细胞膜 | 1层 |
| **合计** |  | **5层** |



> ⚠️ **注意**：进入红细胞**只穿1层**（只进去，不穿出）

---

### 【题型2】O₂从肺泡 → 组织细胞内（被利用）

**路径：**

```
肺泡(气) → 肺泡壁 → 毛细血管壁 → 血浆 → 红细胞(运O₂) 
→ 红细胞(释放O₂) → 血浆 → 毛细血管壁 → 间质 → 组织细胞
```

**逐段计算：**

| 阶段 | 穿膜层数 | 理由 |
| --- | --- | --- |
| 肺泡壁上皮细胞 | 2 | 进+出 |
| 毛细血管壁内皮细胞 | 2 | 进+出 |
| 进入红细胞 | 1 | 只进去 |
| 从红细胞出来 | 1 | 只出来 |
| 毛细血管壁内皮细胞 | 2 | 进+出 |
| 进入组织细胞 | 1 | 只进去（被利用） |
| **合计** | **9层** |  |



> 🔑 **关键**：红细胞**装载和卸载O₂各算1层**，不是2层

---

### 【题型3】葡萄糖从小肠腔 → 小肠上皮细胞 → 血液 → 肝细胞

**路径：**

```
小肠腔(消化道) → 小肠绒毛上皮细胞 → 间质 → 毛细血管壁 → 门静脉 → 肝细胞
```

**逐段计算：**

| 阶段 | 穿膜层数 | 理由 |
| --- | --- | --- |
| 小肠绒毛上皮细胞 | 2 | 进+出 |
| 毛细血管壁细胞 | 2 | 进+出 |
| 进入肝细胞 | 1 | 只进去（被肝细胞摄取） |
| **合计** | **5层** |  |



---

### 【题型4】氨基酸从小肠腔 → 进入血液中的红细胞附近（送进组织细胞）= 小肠→组织细胞

**完整路径：**

```
小肠腔 → 小肠上皮细胞(2) → 间质 → 毛细血管壁(2) → 运输 
→ 组织处毛细血管壁(2) → 间质 → 组织细胞(2)
= 8层
```

---

### 【题型5】氧气从空气 → 被细胞利用，产生CO₂→ 呼出体外（气路）

这个题不涉及穿膜层数，而是**气体扩散路径**：

```
空气 → 肺泡 → 肺泡壁+毛细血管壁(4膜) → 红细胞运O₂ → 组织细胞(1膜)
组织细胞产生CO₂ → 血液 → 肺泡 → 呼出
```

---

### 【题型6】肾小球滤过——特殊情况！

```
血液 → 肾小球 → 肾小囊腔(原尿) → 肾小管 → 血液
```

| 阶段 | 是否算穿膜 |
| --- | --- |
| 肾小球→肾小囊 | **不穿膜**（滤过，通过毛细血管壁的"孔隙"滤过） |
| 肾小管重吸收（进肾小管细胞） | 穿2层（进肾小管上皮细胞） |
| 肾小管重吸收（出肾小管细胞→间质） | 穿2层 |
| 间质→肾小管周围毛细血管 | 穿2层（毛细血管壁） |
| **肾小管上皮细胞的转运合计** | **穿4层**（进2出2→间质），若再进毛细血管+2=**6层** |



---

## 四、总结公式

```
┌─────────────────────────────────────────────────┐
│                                                   │
│   总穿膜层数 = Σ(穿过每个细胞 × 2层) + 特殊情况   │
│                                                   │
│   ● 穿过一个完整细胞 = 2 层                        │
│   ● 进入细胞不出来的（被利用/摄取）= 1 层           │
│   ● 红细胞装O₂ = 1层，卸O₂ = 1层                  │
│   ● 肾小球滤过 = 不计穿膜层                        │
│   • 每段路径逐一累加，标注清楚                      │
│                                                   │
└─────────────────────────────────────────────────┘
```

## 五、易错提醒

| 易错点 | 正确理解 |
| --- | --- |
| 把"过毛细血管壁"算成1层 | 单层细胞 → **2层膜**（进+出） |
| 红细胞装卸O₂各算2层 | 只穿1层（只进去或只出来） |
| 终点是被细胞利用的物质 | 最后进入细胞只算**1层**（不穿出） |
| 肾小球滤过算穿膜 | **不算穿膜**，是滤过作用 |
| 小肠吸收的路径遗漏毛细血管壁 | 上皮细胞(2)+毛细血管壁(2)都要算 |



---

**解题口诀：**

> **"过一个细胞两层膜，进细胞不出一层算；红细胞装卸各一层，滤过穿膜都不算；画路径、标细胞、逐段加、细心算。"**
