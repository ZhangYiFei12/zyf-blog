## 第一部分 静电场（第一、二、三章）★ 高考重点

### 第一章 静电场及其应用

#### 1.1 电荷

- 两种电荷：正电荷（丝绸摩擦玻璃棒，玻璃棒带正电）、负电荷（毛皮摩擦橡胶棒）。
- **电荷量单位 C（库仑）**，元电荷 e = 1.60×10⁻¹⁹ C，所有带电体电荷量都是 e 的整数倍（电荷量子化）。
- 三种起电方式：摩擦起电、接触起电、感应起电。本质都是**电子的转移**（不是创造电荷）。
- **电荷守恒定律**：电荷既不能创生也不能消灭，只能从一个物体转移到另一个物体，或从物体的一部分转移到另一部分，总量保持不变。
- **电荷分配**（接触起电）：两个完全相同的小球接触后，电荷先中和再均分。
  - 例：A 带 +3Q，B 带 −Q，接触后各带 (3Q − Q)/2 = +Q。
- 比荷：电荷量与质量之比 q/m，是带电粒子的重要属性。
- 验电器、静电计原理：同种电荷相斥。

**易错点 ⚠**

1. 摩擦起电的"电"是电子转移，正电荷不移动（金属导体中是自由电子移动）。
2. 电荷量不是无限可分的，一定是 e 的整数倍（但计算题中可近似不写整数倍）。
3. 两个球接触后"先中和再均分"，若原电荷同号则直接平分。

**高考考点/考频/重难点分析**

- **考频**：低频。电荷守恒、元电荷多作为选择题选项或综合题背景出现（与库仑定律、电场强度联动）。
- **常见题型**：选择题（判断起电方式、电荷守恒、感应起电的电荷分布）。
- **重难点**：①接触起电"先中和后均分"的定量计算（两球完全相同才可直接均分）；②感应起电中近端带异号、远端带同号；③元电荷 e 是电荷量的最小单位（电荷量子化）。

#### 1.2 库仑定律 ★

- 内容：真空中两个静止点电荷之间的相互作用力，与电荷量的乘积成正比，与距离平方成反比，方向沿连线。
- 公式：**F = kq₁q₂/r²**，k = 9.0×10⁹ N·m²/C²（静电力常量）。
- 适用条件：①真空（空气中近似）②点电荷（带电体自身大小远小于距离）。
- 方向：同种电荷排斥、异种电荷吸引，方向沿两电荷连线。
- 库仑力符合牛顿第三定律：F₁₂ = F₂₁。

**解题思路**

1. 判断是否可用库仑定律：距离远大于带电体尺寸 → 点电荷。
2. 多个点电荷的库仑力：矢量合成（平行四边形定则）。
3. **三电荷平衡问题**（两同夹异、两大夹小、近小远大）：
   - 三个电荷只在库仑力作用下平衡时，必为"两同号夹一异号"，且中间的异号电荷电荷量最小。
   - 求解套路：对中间电荷列平衡方程，再对两边任一电荷列方程联立。
4. 动态问题：库仑力随距离变化 → 结合受力分析。

**易错点 ⚠**

1. 库仑力与距离平方成反比——距离减半，力变为 4 倍，不是 2 倍。
2. 公式中的 r 是两电荷**球心间距离**；均匀带电球体可视为电荷集中于球心的点电荷（r 为球心距）。
3. 计算时只算大小，方向单独判断（不要带符号算）。
4. 库仑力是性质力，受力分析时要画进去；两电荷间库仑力等大反向（牛顿第三定律），不能认为电荷量大的一方受力大。

**高考考点/考频/重难点分析**

- **考频**：中频~高频。库仑定律与受力分析结合（三电荷平衡、动态平衡）是选择题/计算题常客；2024–2026 年多省卷（浙江、福建、湖南、湖北等）以库仑力为基础命制带电体平衡与运动题。
- **常见题型**：选择题（三电荷平衡、库仑力与重力/弹力/摩擦力平衡、库仑力随距离变化）、计算题第（1）问（求库仑力、临界状态）。
- **重难点**：①**三电荷平衡**（两同夹异、两大夹小、近小远大）及中间电荷电荷量最小——直接可秒杀选择题；②库仑力参与的多力平衡（正交分解）；③动态平衡（两球悬挂、距离变化，用相似三角形法）。

#### 1.3 电场、电场强度 ★

- 电场是电荷周围客观存在的特殊物质，对放入其中的电荷有力的作用（电场的基本性质）。
- **电场强度**：描述电场强弱和方向的物理量。
  - 定义式：**E = F/q**（任何电场适用；q 为试探电荷，E 与 F、q 无关）
  - 点电荷场强：**E = kQ/r²**（Q 为场源电荷）
  - 匀强电场：**E = U/d**（d 为沿电场方向距离）
- 方向：正电荷受电场力方向即电场方向。
- 电场线：
  - 从正电荷（或无穷远）出发，终止于负电荷（或无穷远），不闭合。
  - 电场线不相交、不相切。
  - 疏密表示强弱：密 → 强。
  - 沿电场线电势降低。
- 匀强电场的电场线：平行等距的直线。
- 电场叠加：多个电荷产生的场强用**矢量叠加**（平行四边形定则）。

**解题思路**

1. 求某点场强：确定场源 → 逐个电荷算 E = kQ/r² → 矢量合成。
2. 等量同种/异种电荷连线及中垂线上的场强变化（对称性分析，画图）。
3. E−x 图像、φ−x 图像（后面 φ−x 斜率 = 场强）：读图能力是高频考点。

**易错点 ⚠**

1. E = F/q 是比值定义式，E 与试探电荷 F、q 无关——不能说"E 与 F 成正比、与 q 成反比"。
2. 场强是矢量，叠加必须矢量合成，不能代数相加。
3. 电场线是假想的（理想模型），实际不存在；电场线不是电荷的运动轨迹（除非电场线是直线且电荷初速度为零或沿直线）。
4. 点电荷场强 E = kQ/r² 中，r→0 时 E→∞ 不成立（电荷不能视为点电荷）。
5. 在两点电荷连线的中点，等量同种电荷场强为零（矢量抵消），但电势不一定为零（等量异种电荷连线中点电势为零，场强不为零）。

**高考考点/考频/重难点分析**

- **考频**：高频。场强叠加、电场线分析是选择题必考；"对称法/等效法/割补法"求场强为近年新趋势。
- **常见题型**：选择题（等量同/异种电荷连线及中垂线场强变化、电场线疏密定强弱、E−x 图像）、计算题（场强叠加）。
- **重难点**：①**等量同种/异种电荷**连线和垂直平分线上的场强变化规律（对称点场强等大、方向相反/相同）——图像题核心；②E−x 图像（斜率=场强，面积=电势差）；③场强叠加的对称法（挖补法求带电圆弧/缺口的场强）。

#### 1.4 静电的防止与利用

- 静电平衡：导体内部场强处处为零（合场强为零），导体是等势体，表面是等势面。
- 尖端放电、静电屏蔽（导体壳屏蔽外电场，接地屏蔽内电场）。
- 静电复印、静电除尘、静电喷涂等应用。

**高考考点/考频/重难点分析**

- **考频**：低频。静电平衡、静电屏蔽多作为选择题选项出现（新高考命题偏好生活科技情境，如避雷针、静电吸附、静电除尘）。
- **常见题型**：选择题（静电平衡时内部场强为零、导体表面电荷分布、尖端放电现象、静电屏蔽应用）。
- **重难点**：①静电平衡导体内部合场强为零（不是无电场）；②导体表面曲率越大电荷越密、场强越大（尖端放电原理）；③接地导体的电势为零（电荷流向与中和）。

### 第二章 静电场中的能量 ★

#### 2.1 电势能、电势

- **静电力做功特点**：与路径无关，只与始末位置有关（保守力）→ 静电力是保守力。
- **电势能** Eₚ：电荷在电场中具有的势能。
  - 静电力做正功 → 电势能减少；做负功 → 电势能增加（类比重力做功）。
  - 电势能是相对的，需规定零势能面（通常取无穷远处为零）。
- **电势** φ：φ = Eₚ/q（比值定义）。沿电场线方向电势降低。
  - 电势是标量，有正负。
- 等势面：电势相等的点构成的面。
  - 等势面与电场线处处垂直。
  - 等势面密的地方场强大。
  - 等差等势面（相邻等势面电势差相同）。
- 电场中某点的电势由场源电荷和该点位置决定，与试探电荷无关。

**解题思路**

1. 电势能比较：看电场力做正功还是负功（做功法最常用）。
2. 电势高低比较：沿电场线方向降低；正电荷电势能大处电势高，负电荷反之。
3. 等势面与电场线垂直 → 已知等势面可画电场线，进而判断场强方向。

**易错点 ⚠**

1. 电势是标量，比较大小看代数值（−5 V > −10 V）。
2. 正电荷在电势高处电势能大；负电荷在电势高处电势能小（正反要分清楚）。
3. 电势能为负表示比零势能面低，不代表没有电势能。
4. 场强为零处电势不一定为零（等量同种电荷连线中点）；电势为零处场强不一定为零（等量异种电荷连线中点）。

**高考考点/考频/重难点分析**

- **考频**：高频。电势/电势能比较是选择题必考；常与图像（φ−x、Eₚ−x、v−t）结合。
- **常见题型**：选择题（沿电场线电势变化、正负电荷电势能比较、等势面判断、做功与电势能变化）、计算题第（1）问（求电势差/电势能变化）。
- **重难点**：①电势能比较的三种方法（做功正负、Eₚ = qφ、能量守恒）；②等势面与电场线垂直、等差等势面疏密定场强；③φ−x 图像斜率=场强（正负方向判断易错）。

#### 2.2 电势差 ★

- 定义：**U_AB = φ_A − φ_B**（A 到 B 的电势差）。
- **U_AB = W_AB/q**（电场力做功与电荷量之比，比值定义）。
- 静电力做功：**W_AB = qU_AB**（适用于一切电场！这是最常用的公式）。
- U_AB = −U_BA。

**解题思路**

1. 求做功：W = qU（电场）或 W = qEd（匀强电场沿电场方向）。
2. 注意符号：先规定正方向或直接用正负号代入（电荷正负 × 电势差正负）。

**易错点 ⚠**

1. U_AB 与 W_AB/q 中正负号处理：W 和 q、U 都带符号代入计算，结果的正负自动正确。
2. 电场力做负功，电势能增加，U 和 φ 的符号要一致。

**高考考点/考频/重难点分析**

- **考频**：高频（W = qU 是电场计算的核心桥梁，几乎所有电场计算题都会用到）。
- **常见题型**：选择题（比较电势差大小、判定电势高低）、计算题（求电场力做功、电势差、结合动能定理）。
- **重难点**：①W = qU 中三个量均带符号的代入技巧（先定方向再算大小可避免错号）；②电场力做功与路径无关的运用（非匀强电场也能用 W = qU）；③与动能定理结合：qU = ΔEₖ + ΔEₚ（含重力时）。

#### 2.3 匀强电场中电势差与电场强度的关系 ★

- **E = U/d**（d 是沿电场方向的距离，不是两点间距离）。
- **U = Ed**，仅适用于匀强电场。
- 推论：匀强电场中，同一等势面（垂直于电场线的平面）上各点电势相等；任意两点连线中点的电势等于两端点电势的平均值。
- **等分法求电势**：匀强电场中，沿任意方向电势均匀变化 → 用比例法（等分点）求某点电势。

**解题思路（等分法/几何法）**

1. 已知三角形/矩形三个顶点电势，求第四点或某点电势：用"任意方向电势均匀变化"找等分点。
2. 由电势分布求场强：先找等势面（电势相等的点连线），再作垂线得电场方向，E = U/d。

**易错点 ⚠**

1. E = U/d 中 d 必须是**沿电场方向**的距离（两等势面间垂直距离）。
2. 电势沿电场方向降低最快（场强方向是电势降低最快的方向）。
3. 匀强电场中电场线均匀，电势均匀变化——但只有沿同一方向才均匀。

**高考考点/考频/重难点分析**

- **考频**：高频。等分法求电势、E = U/d 与几何结合是选择题/计算题的常客（全国卷、新高考卷均多次出现）。
- **常见题型**：选择题（已知三点电势求场强方向/大小、等分法求未知点电势、等势面与轨迹结合）、计算题（匀强电场中粒子运动的场强求解）。
- **重难点**：①**等分法**（匀强电场电势均匀变化，用比例找等分点）是求电势/场强方向的"利器"；②场强方向与等势面垂直且指向电势降低方向；③E = U/d 与几何关系（直角三角形、投影）结合。

#### 2.4 电容 ★

- 电容：电容器容纳电荷的本领。**C = Q/U**（比值定义，C 与 Q、U 无关，由电容器本身决定）。
- 单位：法拉 F，1 F = 10⁶ μF = 10¹² pF。
- 平行板电容器：**C = εS/(4πkd)**（ε 为介电常数，S 为正对面积，d 为板间距）。
- 两个典型问题：
  - **Q 不变**（断开电源，电荷不变）：C 变化 → U = Q/C 变化；E = U/d = Q/(Cd) ∝ Q/(εS)，即 E 与 d 无关，只与电荷面密度有关。
  - **U 不变**（始终接电源）：C 变化 → Q = CU 变化；E = U/d 变化。
- 电容器充放电：充电时电荷量增加，板间电压升高；放电相反。

**解题思路**

1. 先判断"Q 不变"还是"U 不变"（断电源 vs 接电源）。
2. 用 C = εS/(4πkd) 判断 C 变化 → 用 Q = CU 或 U = Q/C 判断另一个量 → 用 E = U/d 判断场强。
3. 动态分析口诀：**接电源 U 不变，断电源 Q 不变**。

**易错点 ⚠**

1. C = Q/U 是比值定义，C 不由 Q、U 决定。
2. 平行板电容器插入电介质：ε 增大 → C 增大。
3. 断电源时插入电介质/增大 S：Q 不变，C 增大 → U 减小 → 但 E = Q/(εS) 要具体分析。
4. 静电计测的是**电压 U**（指针偏角反映电势差），不是电荷量——读题注意。

**高考考点/考频/重难点分析**

- **考频**：中频~高频。平行板电容器动态分析是选择题必考点（2024–2026 多省卷连续出现，如山东、广东、浙江等）。
- **常见题型**：选择题（"接电源 U 不变 / 断电源 Q 不变"两种情形下的 C、Q、U、E 变化，静电计偏角，带点微粒受力/运动，P 点电势能变化）。
- **重难点**：①先判断"Q 不变"还是"U 不变"——这是全部动态分析的起点（口诀：接电源 U 不变、断电源 Q 不变）；②断电源时 E 只与电荷面密度 σ = Q/S 有关（E = σ/ε），板距变化 E 不变；③电容器与带电体（微粒平衡/运动）综合，注意受力分析。

### 第三章 带电粒子在电场中的运动 ★★（必考）

#### 3.1 电场中的受力与平衡

- 受力：重力（一般要考虑，除非题中说明忽略）、电场力 F = qE。
- 平衡问题：三力平衡用平行四边形/正交分解法。

**解题思路**

1. 受力分析 → 平衡方程（正交分解沿水平和竖直）。
2. 带电小球悬挂在匀强电场中偏转：tanθ = qE/mg。

#### 3.2 带电粒子在电场中的加速（直线运动）★

- 粒子在匀强电场中做匀加速直线运动（初速度为零或沿电场方向）。
- **动能定理**：**qU = ½mv² − ½mv₀²**（U 为初末位置电势差，适用于一切电场）。
- 非匀强电场也适用动能定理（qU 做功公式）。

**解题思路**

1. 优先用动能定理 qU = ΔEₖ，无需知道电场具体分布。
2. 匀强电场中也可用牛顿第二定律 + 运动学公式。

#### 3.3 带电粒子在电场中的偏转（类平抛）★★

- 条件：粒子垂直进入匀强电场（不计重力）。
- 运动分解：
  - 水平方向：匀速直线运动，x = v₀t，t = L/v₀。
  - 竖直方向：初速度为零的匀加速运动，a = qE/m = qU/(md)。
- 核心公式：
  - 偏转位移（出电场时）：**y = ½at² = qUL²/(2mdv₀²)**
  - 偏转角：**tanθ = v_y/v₀ = qUL/(mdv₀²)**
- 关系：**y = (L/2)·tanθ**（粒子好像从电场中点沿直线射出——重要结论！）
- 出电场后的匀速直线运动：延长线交于入射点与出射点连线的中点。

**解题思路**

1. 明确研究对象 → 判断是否计重力（"电子、质子、α 粒子、离子"一般不计重力；"微粒、油滴、液滴、小球"一般要计重力）。
2. 类平抛三件套：分解 → 列时间相等 → 求 y 和 tanθ。
3. 求打到屏上的位置：屏上偏移 = y + L'·tanθ（L' 为出电场到屏的距离）。
4. 带电粒子能否飞出电场：比较 y 与板间半高。
5. 示波管原理：偏转电压改变 → 荧光屏上光点位置变化（U_y 正比于偏移）。

**易错点 ⚠**

1. 忽略重力与否判断错误——题干出现"微粒/油滴/小球"要考虑重力。
2. 偏转位移 y 和偏转角 tanθ 公式中 L 是**极板长度**，注意与板间距 d 区分。
3. 计算时注意 v₀ 从动能定理 qU₀ = ½mv₀² 求得（加速电压 U₀）。
4. y 与 U（偏转电压）成正比，与 U₀（加速电压）成反比：y = UL²/(4U₀d)。
5. 类平抛中时间 t = L/v₀，不是 L/(v₀ + Δv)。
6. 带电粒子轨迹切线方向 = 速度方向 = 电场力方向（若只受电场力且电场线是直线）。

**高考考点/考频/重难点分析**

- **考频**：**极高（必考）**。带电粒子在电场中的偏转（类平抛）近三年（2024–2026）在浙江、山东、湖北、辽宁、江苏、福建、黑吉辽蒙等大量省份卷中作为选择题或计算题出现，是电磁学第一大考点。
- **常见题型**：选择题（类平抛规律、偏转位移/偏转角比较、功能关系）、计算题（加速+偏转组合、示波管模型、临界飞出/恰好打板、交变电场中的偏转）。
- **重难点**：①"化曲为直"分解（水平匀速、竖直匀加速）与等时性；②加速-偏转组合体的"灵敏度" y/U（与 U₀ 成反比）；③能否飞出电场的临界（y = d/2）；④交变电场中的偏转（分段处理、v−t 图像）；⑤功能关系（动能定理 qU = ΔEₖ）与类平抛的融合。

#### 3.4 静电场综合（图像与能量）

- φ−x 图像：斜率 = 场强 E（斜率为正表示场强沿 −x 方向）。图像陡 → 场强大。
- E−x 图像：面积 = 电势差。
- Eₚ−x 图像：斜率 = −F（电场力）。
- v−t 图像：斜率 = 加速度 → 判断场强变化和受力。

**解题思路**

1. 图像题：先看横纵轴（φ、E、Eₚ），用"斜率/面积"的物理意义转化。
2. 能量守恒：动能 + 电势能 + 重力势能 = 常量（只有电场力做功时，动能 + 电势能守恒）。
3. 电势能与动能转化的判定：电场力做正功，电势能减少。

**高考考点/考频/重难点分析**

- **考频**：高频（图像与能量综合是近年新高考的命题热点，2024–2026 多省卷出现 φ−x / Eₚ−x / v−t 图像题）。
- **常见题型**：选择题（φ−x 斜率定场强、Eₚ−x 斜率定力、轨迹与等势面结合判断粒子的运动/能量变化）。
- **重难点**：①φ−x 图像：斜率 = 场强（正负号表示方向，陡缓表示大小）；②Eₚ−x 图像：斜率 = −电场力；③E−x 图像：面积 = 电势差；④由轨迹弯曲方向判受力（轨迹夹在速度与力之间，力指向轨迹凹侧）→ 判电场方向、电势高低、能量变化。

## 第二部分 恒定电流（第四、五章）★ 必考

### 第四章 电路及其应用

#### 4.1 电流

- 定义：**I = q/t**（单位时间通过导体横截面的电荷量），单位 A。
- 微观表达式：**I = nqSv**（n 为单位体积自由电子数，S 为横截面积，v 为自由电子定向移动速率）。
- 电流方向：正电荷定向移动方向（与电子移动方向相反）。
- 直流电、恒定电流：方向、大小不随时间变化。

**易错点 ⚠**

1. 电流是标量，但有方向（正电荷定向移动方向），不满足矢量合成。
2. 电子定向移动速率很小（约 10⁻⁴ m/s），与"电信号传播速度（光速量级）"不同。
3. q 是**通过横截面**的总电荷量（正负电荷都要算，反向移动要相加）。例：1 s 内有 1 C 正电荷和 1 C 负电荷相向通过截面，I = 2 A。

**高考考点/考频/重难点分析**

- **考频**：低频~中频。电流定义与微观表达式（I = nqSv）常在选择题/填空出现（与电磁感应中的感应电流微观理解结合）。
- **常见题型**：选择题（电流定义、电子定向移动速率计算、q 的取值）、综合题中的小问。
- **重难点**：①I = q/t 中 q 是所有载流子总电荷（正负相向运动要相加）；②I = nqSv 的推导（一段导体体积 n·S·v·t）；③区分定向移动速率与漂移速率、电信号速率。

#### 4.2 电阻、电阻定律

- 电阻：R = U/I（比值定义，R 与 U、I 无关）。
- **电阻定律**：**R = ρL/S**（ρ 为电阻率，只与材料和温度有关）。
- 电阻率：ρ = RS/L。金属电阻率随温度升高而增大；半导体随温度升高而减小；超导体：温度低于临界温度时电阻为零。
- 单位换算：1 kΩ = 10³ Ω，1 MΩ = 10⁶ Ω。

**易错点 ⚠**

1. R = U/I 是定义式，不能说"R 与 U 成正比、与 I 成反比"。
2. 电阻定律中 L 是沿电流方向长度，S 是垂直于电流方向的横截面积。
3. 同种材料导体的电阻与 L 成正比、与 S 成反比——长度减半、横截面积加倍，电阻变为 1/4。
4. 欧姆定律 I = U/R 适用于纯电阻（金属、电解液），**不适用于气体导电和半导体**（非线性）。

**高考考点/考频/重难点分析**

- **考频**：中频。电阻定律多与电学实验（测电阻率、伏安法）结合；欧姆定律/伏安特性曲线常在选择题出现（含非线性元件）。
- **常见题型**：选择题（电阻率与温度关系、电阻定律比较、I−U 图像非线性元件读数）、实验题（测金属丝电阻率）。
- **重难点**：①非线性元件某点电阻 = 该点 U/I（**不是**切线斜率）；②电阻率 ρ 与温度关系（金属升高、半导体降低、超导临界）；③电阻定律与几何形变（拉伸/均匀拉长电阻变化）计算。

#### 4.3 欧姆定律、伏安特性曲线

- 欧姆定律：**I = U/R**（部分电路，纯电阻）。
- I−U 图线（伏安特性曲线）：
  - 直线 → 线性元件（R 恒定，斜率 = 1/R）。
  - 曲线 → 非线性元件（斜率 = 某点电阻的倒数，注意是**该点切线的**倒数值对应的电阻要按 R = U/I 用该点的 U、I 算）。
- 小灯泡的 I−U 曲线：随电压增大，灯丝温度升高，电阻增大，曲线变平缓（斜率减小）。

**易错点 ⚠**

1. 非线性元件某点电阻 = U/I（该点坐标比值），**不是**切线斜率。
2. 二极管正向导电、反向截止（单向导电性）。
3. 气体导电不遵守欧姆定律。

#### 4.4 串并联电路 ★

- 串联：I 相等；U = U₁ + U₂；R = R₁ + R₂；电压按电阻正比分压 U₁/U₂ = R₁/R₂。
- 并联：U 相等；I = I₁ + I₂；1/R = 1/R₁ + 1/R₂；电流按电阻反比分流 I₁/I₂ = R₂/R₁。
- 并联电阻特点：总电阻小于任一电阻；n 个相同电阻 R 并联总电阻为 R/n。
- 串联分压、并联分流是电表改装的基础。

**易错点 ⚠**

1. 并联总电阻越并越小，且小于其中最小者。
2. 混联电路要先找清楚串并联关系（等电位点合并法）。
3. 并联支路中某电阻增大 → 总电阻增大 → 干路电流减小（"串反并同"思想）。

#### 4.5 电表改装（电流表改装）★

- 表头（电流计 G）：满偏电流 I_g、内阻 R_g、满偏电压 U_g = I_gR_g。
- 改装成电压表（大量程）：**串联一个大电阻** R = U/I_g − R_g。
- 改装成电流表（大量程）：**并联一个小电阻** R = I_gR_g/(I − I_g)。
- 读数 = 表盘格数 × 分度值；量程与内阻成正比关系。
- **内接法/外接法**（伏安法测电阻）：
  - 外接法：电压表分流 → 测量值偏小；适合小电阻（R << R_V）。
  - 内接法：电流表分压 → 测量值偏大；适合大电阻（R >> R_A）。
  - 判断：R 与 √(R_A·R_V) 比较。

**易错点 ⚠**

1. 电压表是"串大电阻"，电流表是"并小电阻"，别记反。
2. 内接法测量值 = R + R_A（偏大）；外接法测量值 = RR_V/(R + R_V)（偏小）。
3. 电表读数要估读（最小分度为 1 的估读到 0.1 位，为 2/5 的估读到 1/5 位等）。

#### 4.6 闭合电路欧姆定律 ★★

- 电动势 E：电源把其他能转化为电能的本领，由电源本身决定，与电路无关。单位 V。
- 内阻 r：电源内部电阻。
- **闭合电路欧姆定律**：**I = E/(R + r)**（外电路为纯电阻时）。
- 更一般形式：**E = U_外 + U_内 = U + Ir**。
- 路端电压：**U = E − Ir**（U 随 I 增大而减小）。
- U−I 图像（电源）：纵截距 = E，斜率的绝对值 = r。
- 输出功率：**P_出 = UI = I²R = E²R/(R + r)²**。
  - **当 R = r 时，输出功率最大 P_max = E²/(4r)**（外电路为纯电阻时）。
- 效率：η = U/E = R/(R + r)。

**解题思路（动态电路分析）**

1. 判断变量：某电阻增大或减小（滑动变阻器、开关通断）。
2. 分析方法：**"并同串反"**——与变化电阻并联的支路各量变化相同（同增同减），与变化电阻串联的各量变化相反。
3. 或逐步推理：外电阻变化 → 总电流变化 → 内电压变化 → 路端电压变化 → 各支路。
4. 电源最大输出功率条件 R = r 常考，注意前提"外电路为纯电阻"。

**易错点 ⚠**

1. E 由电源决定，不随外电路变化；U_外 = E − Ir 随外电阻增大而增大（趋于 E）。
2. 路端电压 U 与 I 关系：U = E − Ir，图像斜率大小 = r（**斜率是 −r**）。
3. 纯电阻电路 P = UI = I²R = U²/R 都成立；非纯电阻（电动机）P = UI ≠ I²R，只能 P 电 = UI，P 热 = I²R，P 机 = UI − I²R。
4. 电源短路时 I = E/r（很大），U = 0；断路时 I = 0，U = E。
5. 判断"输出功率是否最大"时注意外电路是否纯电阻（电动机电路不适用 R = r 结论）。
6. 含电动机电路：欧姆定律 I = U/R 对电动机不成立，只能对纯电阻部分用。

### 第五章 电能 电功率

#### 5.1 电功、电功率

- 电功：**W = UIt**（任何电路成立）。
- 电功率：**P = UI**（任何电路成立）。
- 焦耳定律（电热）：**Q = I²Rt**（任何电路成立）。
- 纯电阻电路：W = Q，P = UI = I²R = U²/R。
- 非纯电阻电路（电动机、电解槽）：W > Q，P 电 = P 热 + P 机。
  - P 电 = UI，P 热 = I²R，P 机 = UI − I²R；效率 η = P 机/P 电。

**易错点 ⚠**

1. **W = I²Rt 和 P = I²R 只用于计算电热**，只有纯电阻电路中才等于电功/电功率。
2. 非纯电阻电路中 P = UI > I²R，千万不能用 P = U²/R 算（R 不是等效电阻）。
3. 电动机启动瞬间（转子卡住）是非纯电阻变纯电阻：I = U/R 很大，容易烧坏——用 P = I²R 解释。

**高考考点/考频/重难点分析**

- **考频**：中频~高频。电功/电功率/电热辨析是选择题常客（含电动机、电解槽、充电电池等非纯电阻元件）；也是实验题（测 E、r 涉及功率）的支撑。
- **常见题型**：选择题（纯/非纯电阻功率公式选择、电动机效率、电路总功率分配）、计算题（含电动机电路的能量转化）。
- **重难点**：①纯/非纯电阻判断与公式选择（P 电 = UI、P 热 = I²R 恒成立；P = U²/R 仅纯电阻）；②电动机的输入/输出/热功率三分解；③效率问题（η = P 机/P 电 = U/E 等）。

#### 5.2 电学实验（高考实验大题常考）★

**实验一：测定金属丝的电阻率**

- 原理：R = ρL/S，ρ = RS/L = (U/I)·(πd²/4L)。
- 螺旋测微器（千分尺）：精度 0.01 mm，估读到 0.001 mm（螺旋上的刻度读数到 0.001）。
- 游标卡尺：精度 0.1/0.05/0.02 mm，不估读。
- 电流表外接（金属丝电阻小）、滑动变阻器限流或分压。

**实验二：伏安法测电阻（描绘小灯泡伏安特性）**

- 小灯泡电阻小 → 外接法；电压从零开始 → 滑动变阻器**分压式**接法。
- 分压式：滑片初始在最左（输出电压为零）；限流式：滑片初始在阻值最大处。

**实验三：测定电池电动势和内阻**

- 方法一：U−I 法（电压表+电流表+滑动变阻器），图像截距 = E，斜率 = −r。
- 方法二：U−R 法（电压表+电阻箱）。
- 方法三：I−R 法（电流表+电阻箱）。
- 误差分析：电压表分流 → E 偏小、r 偏小（实际测量的是"电压表并联"后的等效电源）；电流表内接 → E 不变（无误差）、r 偏大（r 测 = r + R_A）。

**解题思路**

1. 滑动变阻器接法选择：需要电压/电流从零开始连续调节、或被测电阻远大于变阻器总阻值时用**分压式**；否则用限流式。
2. 电路实物图连接：先串后并，注意电表正负接线柱（电流从正极流入）。
3. 读数：电流表、电压表按最小分度估读。

**高考考点/考频/重难点分析**

- **考频**：**极高（实验大题必考）**。伏安法测电阻/测金属丝电阻率、测电动势和内阻是高考实验题的常青树（2024–2026 多省卷必有一道电学实验大题）。
- **常见题型**：实验题（画电路图/连实物图、选器材、读表、数据处理、误差分析）、选择题（电表内接外接、分压限流选择）。
- **重难点**：①滑动变阻器分压/限流选择判据（从零调节→分压；测电阻率→限流）；②内接/外接与系统误差方向（大内偏大、小外偏小）；③测 E、r 的三种电路（U−I、U−R、I−R）及误差（电压表分流→E、r 偏小；电流表内接→r 偏大）；④图像法处理数据（截距/斜率物理意义）；⑤读数规则与估读、游标卡尺/螺旋测微器读数。

## 第三部分 磁场与电磁感应（第六、七、八章）★

### 第六章 电磁感应与电磁波初步

#### 6.1 磁场、磁感应强度

- 磁场：磁体或电流周围存在的特殊物质，对磁极和电流有力的作用。
- 磁感线：从 N 极到 S 极（外部），闭合曲线，不相交；疏密表示强弱。
- 磁感应强度 **B**：描述磁场强弱和方向。B = F/(IL)（B 与 F、I、L 无关，比值定义）。
- 单位：特斯拉 T，1 T = 1 N/(A·m)。
- 匀强磁场：磁感线平行等距。
- 常见磁场：条形磁铁、蹄形磁铁、通电直导线（右手螺旋定则：拇指指电流方向，四指弯曲指磁感线方向）、环形电流/螺线管（四指绕电流方向，拇指指 N 极）。

**易错点 ⚠**

1. 磁感线是闭合曲线（内部从 S 到 N，外部 N 到 S），与电场线（不闭合）不同。
2. B = F/(IL) 中 F 是**垂直**于磁场方向的力；导线的放置方式影响受力，不影响 B 本身。
3. 某点磁场方向 = 磁感线切线方向 = 小磁针 N 极指向 = 静止 N 极受力方向。

**高考考点/考频/重难点分析**

- **考频**：中频。磁场方向判断、安培定则常作为电磁感应、磁场力综合题的铺垫出现；单独命题较少（多与安培力、电磁感应联动）。
- **常见题型**：选择题为主（判断磁场方向、磁感线分布、小磁针指向、通电导线磁场叠加），偶有计算题（磁感应强度叠加：B = √(B₁² + B₂²) 等矢量合成）。
- **重难点**：①两个电流（同向/反向平行导线）间安培力方向判断——同向相吸、反向相斥（先定磁场再定力，或直接用"同向相吸、反向相斥"结论）；②磁感应强度叠加（矢量合成，含对称抵消分析）；③区分 B = F/(IL)（比值定义、B 与 F/IL 无关）与 F = BIL（决定力，I⊥B 时）。

#### 6.2 磁通量

- **Φ = BS**（S 为垂直磁场方向的投影面积）。
- 单位：韦伯 Wb，1 Wb = 1 T·m²。
- 磁通量是标量，但有正负（与穿入方向有关），注意抵消。
- 磁通量的变化：ΔΦ = Φ₂ − Φ₁（带正负）。

**易错点 ⚠**

1. Φ = BS 中 S 必须是**垂直于 B 的投影面积**；倾斜平面用 S·sinθ 或分解 B。
2. 磁通量与匝数 N 无关（B·S，不乘 N）。
3. 穿过曲面的磁通量要看穿入穿出的净效果。

**高考考点/考频/重难点分析**

- **考频**：中频。常作为电磁感应选择题的"前奏"考点（判断磁通量变化→有无感应电流），以及计算题（求磁通量变化量 ΔΦ 用于法拉第定律）的基础。
- **常见题型**：选择题（判断磁通量是否变化、比较大小、判定有无感应电流）、计算题第（1）问求 ΔΦ。
- **重难点**：①非匀强磁场中磁通量的定性比较（看磁感线疏密与穿过根数）；②多匝线圈、双向磁场的合磁通量（代数和）；③"磁通量变化率 ΔΦ/Δt"与"磁通量 Φ"的区别（后者大不代表变化率大）。

#### 6.3 电磁感应现象 ★★

- 产生感应电流的条件：**穿过闭合回路的磁通量发生变化**。
- 关键：①回路闭合；②磁通量变化（B 变化、S 变化、夹角变化、回路移动等）。
- 感应电流方向判断：**楞次定律**（增反减同、来拒去留、增缩减扩）。
- 切割磁感线时用**右手定则**（右手：磁感线穿手心，拇指指运动方向，四指指电流方向）。
- 磁通量不变 → 无感应电流（如导线沿磁感线方向平移）。

**解题思路（判断有无感应电流）**

1. 看回路是否闭合。
2. 看磁通量是否变化：B 变？S 变？角度变？穿过回路的磁感线数变？
3. 双磁场问题：比较合磁通量变化。

**易错点 ⚠**

1. 磁通量最大时（正对），变化率可能为零 → 无感应电流（线圈过中性面瞬间）。
2. 磁通量为零时（平行），变化率可能最大。
3. 闭合回路在匀强磁场中平移但不切割（如整体平移）→ 磁通量不变 → 无感应电流。
4. 回路面积变化但磁场也为零的区域，要具体分析。

**高考考点/考频/重难点分析**

- **考频**：高频（含楞次定律方向判断）。2024–2026 年多省卷（黑吉辽蒙、陕晋青宁、江苏、广东、湖南等）均出现，命题常以真实科技情境（磁悬浮列车、无线充电、电磁弹射、电磁压缩、动圈扬声器、感应电炉等）为载体。
- **常见题型**：选择题为主（判断感应电流方向、有无感应电流、线圈/导体运动趋势），计算题综合（后续"导轨+导体棒""线框穿越磁场"模型）。
- **重难点**：①从复杂实际场景中提炼磁通量是否变化（真实情境题）；②楞次定律与右手定则的选择——切割优先右手定则，磁通量变化（非切割）优先楞次定律；③"阻碍"导致的相对运动/面积变化趋势（来拒去留、增缩减扩）常与力学受力分析结合。

#### 6.4 楞次定律与右手定则 ★★

- 楞次定律内容：感应电流具有这样的方向，即感应电流的磁场总要**阻碍引起感应电流的磁通量的变化**。
- "阻碍"不是"阻止"（磁通量照样变化），也不是"相反"（方向相反，变化趋势相反）。
- 应用步骤（四步法）：
  1. 明确原磁场方向。
  2. 判断磁通量增减。
  3. 由楞次定律判断感应电流磁场方向（增反减同）。
  4. 由安培定则（右手螺旋）判断感应电流方向。
- 推论：来拒去留（阻碍相对运动）、增缩减扩（阻碍面积变化）。

**易错点 ⚠**

1. "增反减同"指感应电流的磁场与原磁场方向相反/相同，不是感应电流方向。
2. 楞次定律的"阻碍"对象是**磁通量变化**，本质是能量守恒的体现（阻碍了，才需要外力做功）。
3. 右手定则只适用于"导体切割磁感线"；楞次定律是普遍规律。

**高考考点/考频/重难点分析**

- **考频**：高频（楞次定律方向判断为选择题常客）。
- **常见题型**：选择题（判断感应电流方向、磁铁插拔线圈的电流方向、线框运动趋势），计算题中的方向判定步骤。
- **重难点**：①楞次定律四步法（原磁场方向→增减→感应磁场方向→安培定则定电流）必须熟练；②"来拒去留/增缩减扩"推论直接判断安培力方向（可秒杀选择题）；③楞次定律与能量守恒结合——感应电流的磁场阻碍变化，外力克服安培力做功，能量转化链条：机械能→电能→焦耳热（此链条也是计算题核心）。

#### 6.5 电磁波初步

- 麦克斯韦电磁场理论：变化的磁场产生电场，变化的电场产生磁场。
- 均匀变化的磁场产生恒定电场；周期性变化产生周期性电磁波。
- 电磁波是横波，真空中速度 c = 3×10⁸ m/s，波速 c = λf。
- 电磁波谱（按频率从低到高）：无线电波 → 微波 → 红外线 → 可见光 → 紫外线 → X 射线 → γ 射线。
- 电磁波能传播能量和信息，不需要介质。

**易错点 ⚠**

1. "变化的电场产生磁场"——均匀变化产生恒定磁场，只有周期性变化才产生电磁波。
2. 电磁波传播不需要介质（与机械波不同），机械波传播需要介质。
3. 频率越高，波长越短（c = λf 中 c 一定）。

**高考考点/考频/重难点分析**

- **考频**：低频~中频。新教材"电磁波初步"为新增内容，多以选择题出现，主要考查概念辨析（电磁场理论、电磁波谱、c = λf）。
- **常见题型**：选择题（判断电磁波性质、波谱顺序、电磁波与机械波区别、5G/无线充电等生活情境）。
- **重难点**：①麦克斯韦理论的两句核心（变化的磁场产生电场、变化的电场产生磁场）及"均匀变化→恒定，周期性变化→电磁波"；②电磁波谱频率/波长顺序记忆（无微红可紫 X γ）；③电磁波与机械波的三大区别（不需介质、横波、真空速度 c）。

## 第五部分 各章节易错点集中清单 ⚠

### 电场部分

1. E = F/q 是比值定义，不能说 E ∝ F。
2. 场强叠加用矢量合成；中点处等量同种电荷 E = 0，等量异种电荷 φ = 0（注意区分）。
3. 电场线不相交；不是电荷运动轨迹。
4. 电势能比较：正电荷 φ 大则 Eₚ 大；负电荷反之。
5. W = qU 中三个量都要带正负号。
6. E = U/d 中 d 是沿电场方向距离。
7. 电容器：断电源 Q 不变、接电源 U 不变；静电计测电压。
8. 带电粒子题先判断是否计重力："微粒/油滴/小球"计重力，"电子/质子/离子"不计。
9. 偏转公式中 L 是板长、d 是板距，别混。
10. 带电粒子恰能飞出电场：y = d/2 临界条件。

### 电路部分

11. I = q/t 中 q 含正负电荷总通过量。
12. R = U/I 比值定义；R = ρL/S 决定式。
13. 欧姆定律不适用于气体导电、半导体、非纯电阻。
14. 伏安法：外接测小电阻偏小，内接测大电阻偏大（"大内偏大、小外偏小"）。
15. 电表改装：电压表串大电阻、电流表并小电阻。
16. 非纯电阻电路不能用 P = U²/R、W = U²t/R。
17. 电源 U−I 图像：纵截距 E，|斜率| = r。
18. 动态分析"并同串反"前提是只变一个电阻。
19. 限流式/分压式选择：从零调节用分压。

### 磁场与电磁感应部分

20. 磁感线闭合，电场线不闭合。
21. Φ = BS 中 S 是垂直投影面积；磁通量是标量可抵消。
22. 感应电流条件：回路闭合 + 磁通量变化，缺一不可。
23. 楞次定律"阻碍"的是磁通量**变化**，不是磁通量本身。
24. 右手定则用于切割；楞次定律普遍适用。
25. 磁通量最大时变化率最小（可能为零），磁通量为零时变化率可能最大。
26. 均匀变化的磁场产生恒定电场，不产生电磁波。
27. 电磁波是横波、传播不需介质；机械波需介质。

## 第六部分 通用解题思路（方法论总结）

### 一、受力与运动问题

1. **先受力分析**：重力？电场力（qE）？安培力/洛伦兹力（后两章）？弹力？摩擦力？
2. 判断运动性质：平衡（a = 0）→ 合力为零；匀变速 → 牛二 + 运动学；曲线 → 分解。
3. 优先考虑**能量观点**（动能定理、能量守恒），少走弯路。

### 二、静电场问题

1. 判断计不计重力（看对象名称）。
2. 匀强电场：优先用 qU = ΔEₖ、E = U/d；非匀强：只用 W = qU、动能定理。
3. 类平抛三件套：分解（水平匀速、竖直匀加速）→ 等时性 → 求 y、tanθ。
4. 图像题：斜率、面积、截距的物理意义逐项转化。

### 三、电路问题

1. 动态电路：只变一个电阻 → 用"并同串反"或逐推法。
2. 闭合电路计算：I = E/(R+r) → U = E − Ir → 功率公式选对。
3. 电表改装：先算表头满偏电压，再算需串/并的电阻。
4. 非纯电阻：分清楚 P 电、P 热、P 机，用 P 电 = UI、P 热 = I²R。

### 四、电磁感应问题

1. 判断有无感应电流：闭合？磁通量变？
2. 判断方向：切割 → 右手定则；普遍 → 楞次定律四步法。
3. 综合计算（动量、能量视角）：感应电流阻碍变化 → 外力做功转化为电能 → 焦耳热（后续章节）。

### 五、实验题通用思路

1. 明确实验原理 → 写出核心公式。
2. 选器材：电表量程、滑动变阻器接法（分压/限流）。
3. 连实物图：串并联顺序、正负接线柱。
4. 数据处理：描点作图 → 截距/斜率 → 待测量。
5. 误差分析：内接/外接、电压表分流、电流表分压。

## 附：常考二级结论与速记口诀

1. **电场**："沿场线电势降，正电荷高处能大，负电荷高处能小。"
2. **电容**："接电源 U 不变，断电源 Q 不变，ε 大 S 大 C 大。"
3. **偏转**："y 与板长平方成正比，与 d、v₀² 成反比；y = (L/2)tanθ。"
4. **电表**："大内偏大（大电阻内接，测量偏大），小外偏小。"
5. **改装**："电压串大阻，电流并小阻。"
6. **闭合电路**："外阻越大路端越高，短路电流 E/r，断路电压 E。"
7. **最大功率**："内外相等 R = r 时，输出功率最大 E²/4r。"
8. **楞次定律**："增反减同、来拒去留、增缩减扩、阻碍相对运动。"
9. **电磁波谱**："无微红可紫 X γ"（无线电波、微波、红外、可见光、紫外、X 射线、γ 射线，频率递增）。
10. **感应电流条件**："闭合 + 磁通量变化，缺一不可。"

## 结语

- 必修第三册的核心是**三条主线**：电场（力与能）→ 电路（电流与能量）→ 电磁感应（磁生电与电磁波）。
- 复习建议：
  1. 先过一遍知识点清单（本文第一~三部分），把公式默写一遍。
  2. 重点刷"带电粒子偏转、闭合电路动态分析、楞次定律"三类大题。
  3. 实验题必考伏安法测电阻与测电动势内阻，务必动手画图。
  4. 考前看"易错点清单"和"速记口诀"。
