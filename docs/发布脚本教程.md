# 📦 publish-release.mjs 使用教程（大文件发布）

> 适用：发布**超过 100MB**（最大 2GB）的安装包/压缩包。
> ≤100MB 的文件直接用网页后台「📦 下载」上传即可，不需要本脚本。

## 前置条件（一次性）

1. 本机已登录 GitHub CLI：
```bash
gh auth status
# 应显示 Logged in to github.com account ZhangYiFei12
```

2. 能访问 github.com（网络正常时）

## 基本用法

```bash
cd D:\deepseek\harness\zyf-blog

node tools/publish-release.mjs "安装包完整路径.exe"
```

**最简单的一行**：脚本自动用文件名当显示名、自动生成 tag、自动登记并推送。
约 1 分钟后 https://zyf2026.pages.dev/downloads.html 出现下载项。

## 完整参数（推荐）

```bash
node tools/publish-release.mjs "D:\下载\MyApp-Setup.exe" ^
  --tag v1.0.0 ^
  --name "我的应用 1.0" ^
  --desc "Windows x64 安装版，含自动更新" ^
  --category "软件"
```

| 参数 | 说明 | 缺省 |
| --- | --- | --- |
| `--tag v1.0.0` | Release 版本标签 | 自动生成 `dl-日期-随机` |
| `--name "显示名"` | 下载页显示的软件名 | 用文件名 |
| `--desc "说明"` | 下载页的简介文字 | 空 |
| `--category "分类"` | 分类徽章 | `软件` |

## 脚本做了什么（自动）

1. 检查 tag 是否已有 Release，没有则创建
2. 上传文件到 Release（大文件会显示进度/耗时）
3. 登记到 `data/downloads.json`（store: release）
4. `git push` → 触发 Cloudflare 自动部署

## 常见问题

| 现象 | 解决 |
| --- | --- |
| `gh: not logged in` | 先 `gh auth login` |
| 上传很慢/中断 | 网络问题，重跑一次即可（`--clobber` 会覆盖同名资产） |
| 想更新某版本文件 | 用相同 `--tag` 重跑，资产被覆盖，下载页同一条记录更新 |
| 想删除 | 网站后台「📦 下载」→ 删除（Release 资产一起删） |
