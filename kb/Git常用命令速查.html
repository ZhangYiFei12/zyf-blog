Git 常用命令速查

基础操作

git status              # 查看工作区状态
git add -A              # 暂存所有改动
git commit -m "msg"     # 提交
git push origin main    # 推送

分支管理

命令说明
git branch列出本地分支
git switch -c feat新建并切换分支
git merge feat合并分支

回滚

  • git restore <file> —— 丢弃工作区改动
  • git reset --soft HEAD~1 —— 撤销提交但保留改动
  • git revert <sha> —— 生成一个反向提交（安全，推荐用于已推送）
